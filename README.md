# Portfólio — António Cassule Maurício

Site pessoal de uma página, feito à mão em HTML, CSS e JavaScript, sem build nem dependências.

## Ver o site

Abrir o ficheiro `index.html` no navegador. Ou, a partir desta pasta:

```bash
python3 -m http.server 3000
```

e visitar `http://localhost:3000`.

## Estrutura

- `index.html` — conteúdo de todas as secções e o poster em SVG
- `styles.css` — tema escuro, tipografia e responsividade
- `script.js` — revelar ao scroll, barra de progresso, parallax do poster, menu móvel e relógio de Luanda
